# ![Inkdown logo](./assets/inkdown-mark.svg) Inkdown

A premium, privacy-first tool for converting between rich text and Markdown right in the browser.

No account, no server, no build step. Open the file, paste your content, and convert.

## What It Does

- Convert `Rich Text → Markdown`
- Convert `Markdown → Rich Text`
- Format content with a built-in editor toolbar
- Copy or download the result instantly
- Work fully offline after the page loads

## How to Use It

1. Clone or download the `Inkdown` repository.
2. Open [index.html](./index.html) in any modern browser.
3. Choose a conversion direction.
4. Paste or type your content.
5. Copy or download the output.

## Clone

```bash
git clone https://github.com/aditya-pandya/Inkdown.git
cd Inkdown
```

## Features

- Real-time conversion as you type
- Rich text formatting controls for headings, lists, links, images, blockquotes, and more
- Markdown preview with syntax highlighting
- Light and dark theme support
- Local autosave so your draft is restored on your next visit

## Privacy

Your content stays local. The app runs entirely in the browser and does not send your text to an external service.
