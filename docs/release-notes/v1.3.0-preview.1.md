# Asterism 1.3.0-preview.1

This prerelease preview is for Apple Silicon Macs. Download [Asterism-1.3.0-preview.1-arm64.dmg](https://github.com/aditya-pandya/asterism/releases/download/v1.3.0-preview.1/Asterism-1.3.0-preview.1-arm64.dmg) or [Asterism-1.3.0-preview.1-arm64.zip](https://github.com/aditya-pandya/asterism/releases/download/v1.3.0-preview.1/Asterism-1.3.0-preview.1-arm64.zip). The app is ad-hoc signed, has no Developer ID signature, and is not notarized.

## What's new

- Open Markdown directly in Read, with browser File System Access support where available.
- Save supported browser-opened Markdown files in place or use Save As. Before overwriting, Asterism compares the file with the version opened and asks how to proceed if it changed. Missing files require Save As. Browsers without these APIs use download fallback.
- Link a folder in supported browsers to resolve nearby images and Markdown links.
- Jump to headings from a searchable heading list.
- Copy the rendered document with formatting, or print it.
- Use formatting and native document shortcuts, listed in Settings. Enter continues Markdown lists and exits an empty list item.
- Choose Paper or Sage light palettes and Midnight dark palette alongside Default, with Light, Dark, or Auto appearance.
- Convert pasted rich text and Markdown between the formatted and source panes. Source-fidelity checks warn about common syntax that may change during formatted editing; they are a mitigation, not complete coverage.

## Verification status

`npm test` passes 25/25 tests. All four Electron smoke scripts pass: core features, Markdown round-trip, source fidelity, and recovered-draft reattachment.

On the packaged Mac app, physical Command-B, Command-Z, Shift-Command-9, and Command-/ were verified without duplicate dispatch. Chrome verification covered File System Access Open into Read, in-place Save after OS permission, disk-content confirmation, canceling an external-change conflict while retaining the external file, and Save As with the copy verified on disk. After Save As, Link folder loaded a 1280-pixel-wide PNG and relative `next.md` navigation worked. One folder association lookup on the old handle returned null after an external change; Save As and linking the fresh handle restored access. This does not establish every permission or handle edge case.

The DMG and ZIP were built under `dist/preview-1.3.0`. `codesign --verify --deep --strict` passed, and packaged asar contents matched the source. Tauri desktop interaction remains untested; Rust checks do not establish runtime behavior. See the [core product audit](../CORE_AUDIT.md) for evidence and limits.
