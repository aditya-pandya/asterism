# Asterism 1.3.0-preview.3

This prerelease preview is for Apple Silicon Macs. Download [Asterism-1.3.0-preview.3-arm64.dmg](https://github.com/aditya-pandya/asterism/releases/download/v1.3.0-preview.3/Asterism-1.3.0-preview.3-arm64.dmg) or [Asterism-1.3.0-preview.3-arm64.zip](https://github.com/aditya-pandya/asterism/releases/download/v1.3.0-preview.3/Asterism-1.3.0-preview.3-arm64.zip). The app is ad-hoc signed, has no Developer ID signature, and is not notarized. There is no automatic updater, so install new versions manually. For first-launch guidance, see the [README](../../README.md#how-to-open-it).

## What's new

- A full visual redesign that matches the new website: Hanken Grotesk for the interface, Bricolage Grotesque for headings, refined light and dark palettes, and calmer toolbars and panes.
- Changing theme now sweeps the new palette in from where you clicked. With reduced motion on, it switches instantly.
- A new empty state with a drawn asterism mark and keyboard hints for pasting or opening a file.
- Settings open as a side sheet, with each theme shown as a colour swatch.
- Quieter reading typography: an asterism section break, open tables and a subtler Copy button on code blocks.
- The save status now shows a coloured dot for saved, unsaved and warning states.

## Verification status

`npm test` passes 25/25 unit tests. The light-theme contrast, dark-theme, UI polish, core features, Markdown round-trip, source-fidelity and recovered-draft smoke scripts all pass.

The Mac build is for Apple Silicon and is ad-hoc signed, not notarized. The redesign was checked in Chromium and Electron; Safari rendering of the website was not tested.
