# Inkdown 1.1.0 - Apple Silicon Preview

This release packages Inkdown as a native macOS app for Apple Silicon Macs.

## Downloads

- `Inkdown-1.1.0-arm64.dmg` - recommended
- `Inkdown-1.1.0-arm64.zip` - direct app archive

## Important Note

This build is unsigned and not notarized. That keeps the release free of Apple Developer Program requirements, but macOS Gatekeeper may warn on first launch.

To open the app after installing it, Control-click or right-click Inkdown, choose Open, then confirm Open. If macOS still blocks it, use System Settings -> Privacy & Security -> Open Anyway.

## What's New

- Native macOS packaging via Electron
- Apple Silicon-only preview build
- Rich Text -> Markdown conversion
- Markdown -> Rich Text conversion
- Markdown reader mode
- Bundled libraries and syntax-highlighting assets for offline use
- No runtime CDN or Google Fonts dependency
- Cleaned macOS package metadata to avoid unused camera, microphone, audio, and Bluetooth permission strings
- Hardened renderer permissions and external-link handling

## Verification

- `npm audit --audit-level=high` passes with 0 vulnerabilities
- `codesign --verify --deep --strict` passes for the packaged app
- `hdiutil verify` passes for the DMG
- `spctl` rejects the app because it is unsigned/not notarized, which is expected for this preview
