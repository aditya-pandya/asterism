# Asterism 1.3.0-preview.2

This prerelease preview is for Apple Silicon Macs. Download [Asterism-1.3.0-preview.2-arm64.dmg](https://github.com/aditya-pandya/asterism/releases/download/v1.3.0-preview.2/Asterism-1.3.0-preview.2-arm64.dmg) or [Asterism-1.3.0-preview.2-arm64.zip](https://github.com/aditya-pandya/asterism/releases/download/v1.3.0-preview.2/Asterism-1.3.0-preview.2-arm64.zip). The app is ad-hoc signed, has no Developer ID signature, and is not notarized. There is no automatic updater, so install new versions manually. For first-launch guidance, see the [README](../../README.md#how-to-open-it).

## What's new

- Polished app typography.
- A hierarchical, collapsible document outline sidebar that highlights the active section or current heading. Toggle it with Command-Option-O.
- Exactly three dark themes: Midnight (navy and mint), Onyx (black and gold), and Ember (charcoal and copper).
- Settings that used the legacy dark default now migrate to Onyx.
- Find and Replace in Markdown source now matches the exact source text, fixes a blank-line bug, and supports undo.

## Verification status

`npm test` passes 25/25 unit tests. The UI and dark-theme smoke scripts pass, as do the previous core, source-fidelity, recovered-draft, and Markdown round-trip checks.

The Mac build is for Apple Silicon and is ad-hoc signed, not notarized. A physical check of the native keyboard accelerators was not completed because the UI automation tool timed out, so they are not verified in this release.
