# Asterism 1.2.0 - Inkdown gets a new name and a calmer look

Inkdown is now **Asterism**, named for the ⁂ mark. It is the same private, offline rich text and Markdown converter, with a new name, a new icon, and a redesigned interface.

## Downloads

- `Asterism-1.2.0-arm64.dmg` - recommended
- `Asterism-1.2.0-arm64.zip` - direct app archive
- `Asterism-1.2.0-tauri-arm64.dmg` - experimental native build made with Tauri

All builds are for Apple Silicon Macs.

## Important Note

These builds are unsigned and not notarized, because I do not have a paid Apple Developer certificate. macOS Gatekeeper warns about any app that is not signed and notarized. The warning is about the missing certificate, not about anything the app does. The source is in this repository, and the app makes no network requests of its own.

To open the app after installing it, Control-click or right-click Asterism, choose Open, then confirm Open. If macOS still blocks it, use System Settings -> Privacy & Security -> Open Anyway.

## Upgrading from Inkdown

Your saved document and settings carry over. The Electron app keeps using its existing Inkdown data folder, and the Tauri build keeps the same app identifier. If you installed Inkdown 1.1.0, delete the old Inkdown app after moving Asterism to Applications.

## What's New

- New name, icon, and favicon
- A top bar with an Edit and Read switch, plus Open, appearance, and Settings buttons
- A formatting toolbar that is always in view, with clearer icons
- A first-run screen with Paste and Open file buttons
- Copy is the single main action, and Copy and Save dim while the document is empty
- A status bar with word count, save status, and a two-step Clear with Undo
- A Settings sheet with segmented controls and a list of keyboard shortcuts
- Toasts for open, save, and download
- Quiet motion: a sliding Edit and Read switch, press feedback, active formatting state, a copy check mark, a smooth theme change, and gentle entrances and exits. All of it is skipped when your Mac is set to reduce motion
- Pasting now replaces the old file name, and Save on an empty document says so instead of saving a blank file
- Tauri build of the same app, alongside the Electron one
- Higher-contrast text and labels

## Verification

- `npm audit --omit=dev` reports 0 vulnerabilities in what ships. `npm audit` flags advisories in build tools (`electron-builder` and `xmldom`), which are not part of the app
- `codesign --verify --deep --strict` passes for the app inside both DMGs
- `hdiutil verify` passes for both DMGs
- `spctl` rejects the apps because they are unsigned and not notarized, which is expected
- Electron app: tested an existing Inkdown data folder (reused, saved document survives a relaunch) and a fresh install
- Tauri app: builds and starts. Its interface was not tested beyond launch
