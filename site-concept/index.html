Open a file. Read it. Edit when you need to.

Asterism is a minimal, local Markdown reader and editor. The formatted and Markdown panes share one document, so you can also paste rich text and copy it back out as clean Markdown.

Open the app Download for Mac (Apple Silicon) Source on GitHub

  • Read first. Markdown, text and HTML open as a formatted page.
  • Edit beside it. Formatted text and Markdown stay in sync.
  • Find in either view, with replace in Markdown.
  • Jump to any heading from a searchable list.
  • Themes. Paper, Sage and Midnight, light, dark or auto.
  • Save back to the same file, or print the page.

Before you download

The Mac preview runs on Apple Silicon only. It is ad-hoc signed and not notarized, so macOS may block the first launch. The README explains how to open it anyway.

Your text stays on your machine and Asterism does not upload it. Images in a document can still load from the web. Converting pasted rich text is best effort, and complex layouts may not survive.
