Help & Markdown Reference

How to Use

  1. Choose conversion direction: Rich Text → Markdown or Markdown → Rich Text
  2. Enter or paste your content in the input panel
  3. View the converted output in real-time
  4. Copy or download the result

Keyboard Shortcuts

  • Ctrl+B - Bold
  • Ctrl+I - Italic
  • Ctrl+U - Underline
  • Ctrl+K - Insert Link

About

This is a standalone, privacy-focused converter that runs entirely in your browser. No data is sent to external servers.
